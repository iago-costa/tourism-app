# 🧠 Skills, Agents & System Prompt Architecture

> Senior-level AI agent definitions for engineering excellence across all disciplines.

## Structure

```
.agents/
├── skills/           # Technical skill trees per role
├── agents/           # Agent persona & behavioral rules
└── system-prompts/   # Full system prompts for AI assistants
```

Each sub-directory mirrors the same **8 categories**:

| Category | Roles |
|---|---|
| `backend/` | Backend Engineer · API Architect · Platform Engineer · Integration Engineer |
| `devops/` | DevOps Engineer · SRE · Platform Engineer · Infrastructure Architect |
| `frontend/` | Frontend Engineer · UI Engineer · Design System Engineer · Web Perf Engineer |
| `data/` | Data Engineer · Analytics Engineer · BI Developer · Data Architect |
| `mobile/` | iOS Engineer · Android Engineer · React Native Engineer · Flutter Engineer |
| `security/` | Security Engineer · AppSec Engineer · Pentester · Cloud Security Architect |
| `ml-ai/` | ML Engineer · MLOps Engineer · AI Product Engineer · LLM Engineer |
| `leadership/` | Tech Lead · Staff Engineer · Engineering Manager · Solution Architect |

## Usage

1. **Skills** — Reference when configuring agent capabilities and knowledge domains
2. **Agents** — Use as agent definitions in AI orchestration frameworks (e.g., CrewAI, LangGraph, AutoGen)
3. **System Prompts** — Drop directly into LLM system messages for role-specific AI assistants

All definitions are calibrated for **senior-level** professionals with deep expertise, architectural thinking, and mentorship capabilities.
