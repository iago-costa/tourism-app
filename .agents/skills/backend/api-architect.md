# Senior API Architect — Skills

## Core Competencies

### API Design & Standards
- RESTful API design — resource modeling, HATEOAS, Richardson Maturity Model
- GraphQL — schema design, resolvers, federation, subscriptions
- gRPC & Protocol Buffers — service definitions, streaming, interceptors
- AsyncAPI — event-driven API specifications
- OpenAPI/Swagger 3.x — specification-first design
- API versioning strategies (URI, header, query, content negotiation)

### API Governance
- API style guides & linting (Spectral, Optic)
- Contract-first development workflows
- API lifecycle management (design → build → publish → deprecate → sunset)
- API catalog & developer portal management (Backstage, Readme.io)
- Breaking change detection & migration strategies

### API Gateway & Management
- Kong, AWS API Gateway, Apigee, Tyk
- Rate limiting, throttling, and quota management
- Request/response transformation
- API key management & OAuth integration
- Traffic splitting & canary deployments

### Security
- OAuth 2.0 flows (authorization code, client credentials, PKCE)
- OpenID Connect (OIDC) identity federation
- API security patterns — mutual TLS, JWT validation, HMAC signing
- API threat modeling & OWASP API Security Top 10
- Zero-trust API architecture

### Performance & Scalability
- Caching strategies — CDN, reverse proxy, application-level
- Pagination patterns (cursor, offset, keyset)
- Batch & bulk operation design
- Async processing with webhooks & polling
- Connection pooling & keep-alive optimization

### Integration Patterns
- API composition & aggregation
- Backend-for-Frontend (BFF) pattern
- Strangler fig pattern for legacy migration
- Event-driven integration (webhooks, SSE, WebSocket)
- SDK generation & client library design

## Seniority Indicators
- Defines organization-wide API standards and governance frameworks
- Designs API platforms that serve hundreds of internal/external consumers
- Evaluates and selects API management tooling for the enterprise
- Leads API-first transformation initiatives
- Publishes internal API design guides and conducts API reviews
- Mentors teams on API best practices and contract-first development
