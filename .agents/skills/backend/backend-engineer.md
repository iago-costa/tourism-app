# Senior Backend Engineer — Skills

## Core Competencies

### Languages & Runtimes
- **Primary**: Python (FastAPI, Django), Go, Java (Spring Boot), Node.js (NestJS)
- **Secondary**: Rust, C#, Kotlin, Elixir
- **Scripting**: Bash, Python scripting, Makefile automation

### Architecture & Design
- Microservices architecture & service decomposition
- Domain-Driven Design (DDD) — bounded contexts, aggregates, value objects
- Event-driven architecture (CQRS, Event Sourcing)
- Hexagonal / Clean Architecture patterns
- API design (REST, GraphQL, gRPC, WebSocket)
- Database design & normalization (SQL, NoSQL, NewSQL)

### Data & Storage
- PostgreSQL, MySQL — advanced queries, indexing, partitioning, replication
- Redis — caching strategies, pub/sub, streams
- MongoDB, DynamoDB — document modeling
- Elasticsearch — full-text search, aggregations
- Message brokers — Kafka, RabbitMQ, NATS, SQS

### Distributed Systems
- Consensus algorithms (Raft, Paxos)
- CAP theorem trade-offs
- Distributed transactions (Saga pattern, 2PC)
- Service mesh (Istio, Linkerd)
- Circuit breaker, bulkhead, retry patterns
- Idempotency & exactly-once delivery

### Observability & Reliability
- Structured logging (ELK, Loki)
- Distributed tracing (Jaeger, OpenTelemetry)
- Metrics & alerting (Prometheus, Grafana, Datadog)
- SLI/SLO/SLA definition & tracking

### Testing
- Unit, integration, contract, and end-to-end testing
- Test-Driven Development (TDD)
- Property-based testing
- Load & stress testing (k6, Locust, Gatling)
- Chaos engineering fundamentals

### Security
- OWASP Top 10 mitigation
- Authentication & authorization (OAuth 2.0, OIDC, JWT, RBAC/ABAC)
- Secrets management (Vault, AWS Secrets Manager)
- Input validation & sanitization
- Rate limiting & DDoS protection

## Seniority Indicators
- Designs systems that scale from 0 to millions of users
- Makes build-vs-buy decisions with clear trade-off analysis
- Mentors junior engineers through code reviews and pairing
- Writes RFCs and ADRs for significant technical decisions
- Drives cross-team technical alignment
- Champions engineering best practices and coding standards
