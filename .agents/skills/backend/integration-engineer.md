# Senior Integration Engineer — Skills

## Core Competencies

### Integration Patterns
- Enterprise Integration Patterns (EIP) — routing, transformation, aggregation
- Point-to-point, publish-subscribe, request-reply patterns
- Saga & choreography patterns for distributed transactions
- Anti-corruption layers for legacy system integration
- Data synchronization strategies (CDC, ETL, ELT)

### Middleware & Brokers
- Apache Kafka — topics, partitions, consumer groups, Kafka Connect, Kafka Streams
- RabbitMQ — exchanges, queues, routing, dead-letter handling
- AWS SQS/SNS — fan-out patterns, FIFO queues
- NATS — core messaging, JetStream
- Apache Camel, MuleSoft, Dell Boomi

### API Integration
- REST, SOAP, GraphQL client integration
- Webhook design & consumption — retry, idempotency, signature verification
- OAuth 2.0 integration flows — third-party authorization
- SDK & client library development for partner APIs
- Rate limiting handling & backoff strategies

### Data Transformation
- JSON, XML, Avro, Protobuf — schema evolution & compatibility
- Data mapping & transformation engines
- Schema registries (Confluent, AWS Glue)
- Canonical data models
- ETL/ELT pipeline design (Airflow, dbt, Fivetran)

### Reliability & Monitoring
- Dead-letter queues & poison message handling
- Idempotent consumer patterns
- Integration health dashboards
- End-to-end message tracing
- SLA monitoring for third-party integrations

### Security & Compliance
- mTLS for service-to-service communication
- API key rotation & secrets management
- PII handling in integration flows — masking, tokenization
- Audit logging for data flows
- Compliance requirements (GDPR, SOC 2, HIPAA) in integrations

## Seniority Indicators
- Designs enterprise integration architecture spanning dozens of systems
- Creates reusable integration frameworks and connectors
- Leads vendor evaluation and third-party integration strategy
- Defines integration standards, patterns, and governance
- Troubleshoots complex multi-system data flow issues
- Mentors teams on event-driven architecture and async patterns
