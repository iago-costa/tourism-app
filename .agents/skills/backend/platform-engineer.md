# Senior Platform Engineer (Backend) — Skills

## Core Competencies

### Platform Design
- Internal Developer Platform (IDP) architecture
- Platform-as-a-Product mindset — user research, roadmaps, adoption metrics
- Self-service infrastructure provisioning
- Golden paths & paved roads for development teams
- Multi-tenancy design & resource isolation

### Infrastructure as Code
- Terraform, Pulumi, CrossPlane — modular, reusable infrastructure
- Kubernetes operators & custom controllers
- Helm charts & Kustomize overlays
- GitOps workflows (ArgoCD, Flux)
- Infrastructure testing (Terratest, OPA/Gatekeeper)

### Containerization & Orchestration
- Docker — multi-stage builds, security hardening, layer optimization
- Kubernetes — advanced scheduling, HPA/VPA, pod disruption budgets
- Service mesh — Istio, Linkerd, Consul Connect
- Serverless platforms — Knative, AWS Lambda, Cloud Run

### CI/CD Platforms
- GitHub Actions, GitLab CI, Jenkins, Tekton
- Pipeline-as-code design & standardization
- Build acceleration (caching, parallelism, incremental builds)
- Artifact management (Artifactory, Nexus, ECR/GCR)
- Release management & progressive delivery

### Developer Experience
- CLI tooling for developer workflows
- Local development environments (devcontainers, Tilt, Skaffold)
- Documentation-as-code (Backstage, Docusaurus)
- Developer onboarding automation
- Template & scaffolding systems (Cookiecutter, Yeoman)

### Observability Platform
- Centralized logging architecture (ELK, Loki, CloudWatch)
- Metrics aggregation pipelines (Prometheus, Thanos, Cortex)
- Distributed tracing infrastructure (Jaeger, Tempo, X-Ray)
- Alerting frameworks & runbook automation

## Seniority Indicators
- Designs and evolves the organization's Internal Developer Platform
- Reduces time-to-production for developer teams by 50%+
- Defines platform SLAs and measures developer satisfaction (DX surveys)
- Drives adoption of platform capabilities across engineering org
- Balances innovation with stability in platform evolution
- Champions platform engineering culture and self-service principles
