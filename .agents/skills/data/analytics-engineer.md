# Senior Analytics Engineer — Skills

## Core Competencies

### Data Modeling
- Dimensional modeling (Kimball, Inmon, Data Vault 2.0)
- dbt — models, tests, snapshots, macros, packages
- Metrics layer — MetricFlow, Cube, Lightdash
- Slowly changing dimensions and temporal modeling
- Entity-centric modeling for customer 360

### SQL Mastery
- Advanced window functions and analytics
- Common Table Expressions (CTEs) and recursive queries
- Performance optimization — query plans, indexing, materialization
- Cross-database SQL dialects (BigQuery, Snowflake, Redshift, Postgres)
- Jinja templating in dbt for dynamic SQL

### Data Quality
- dbt tests — unique, not_null, accepted_values, relationships, custom
- Great Expectations — suites, checkpoints, data docs
- Data freshness monitoring and SLAs
- Anomaly detection in data pipelines
- Data contracts between producers and consumers

### Analytics & Visualization
- BI tools — Looker/LookML, Tableau, Power BI, Metabase, Superset
- Semantic layer design and metrics definitions
- Dashboard design best practices
- Self-service analytics enablement
- Data storytelling and insight communication

### Workflow & Collaboration
- dbt Cloud / CLI — development workflow, CI/CD, documentation
- Version control for analytics (Git-based workflows)
- Code review processes for analytics code
- Cross-functional collaboration (data, product, engineering)
- Analytics engineering as a discipline — best practices, standards

### Data Governance
- Data documentation — dbt docs, data catalogs
- Data lineage and dependency tracking
- Naming conventions and style guides
- Access control and row-level security
- PII handling and compliance in analytics

## Seniority Indicators
- Architects the analytics layer serving hundreds of business users
- Defines data modeling standards and style guides for the organization
- Creates self-service analytics frameworks reducing ad-hoc requests by 80%
- Drives data quality and trust programs
- Mentors analysts and junior analytics engineers
- Bridges the gap between data engineering and business stakeholders
