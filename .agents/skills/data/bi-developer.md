# Senior BI Developer — Skills

## Core Competencies

### BI Platforms
- Looker / LookML — explores, dashboards, PDTs, derived tables
- Tableau — calculated fields, LOD expressions, dashboard design, Tableau Server
- Power BI — DAX, M (Power Query), dataflows, deployment pipelines
- Metabase / Superset — open-source BI deployment and customization
- Embedded analytics — Looker Embed, Tableau Embedded, Cube.js

### Data Visualization
- Chart selection best practices (Tufte, Few)
- Dashboard UX design — layout, hierarchy, interactivity
- KPI design — definitions, calculations, benchmarks
- Accessibility in data visualization
- Mobile-optimized dashboards and reports

### Semantic Modeling
- LookML modeling — views, explores, derived tables, refinements
- DAX measures and calculated columns
- Semantic layer architecture — Cube, MetricFlow, Looker
- Metric definitions and business logic centralization
- Multi-dimensional analysis (OLAP cubes)

### ETL/ELT Integration
- Source system integration (APIs, databases, files)
- Data warehouse optimization for BI workloads
- Incremental refresh and caching strategies
- Real-time dashboarding architectures
- Data preparation and transformation (Power Query, Prep Builder)

### Governance & Performance
- Dashboard performance optimization
- Row-level and column-level security
- Content management and folder organization
- Usage analytics and adoption tracking
- Report distribution and scheduling

### Advanced Analytics in BI
- Statistical functions in BI tools
- Forecasting and trend analysis
- Cohort analysis and retention
- Funnel analysis and conversion tracking
- Geographic and spatial analysis

## Seniority Indicators
- Architects enterprise BI platforms serving thousands of users
- Defines BI standards, templates, and governance frameworks
- Creates reusable LookML/DAX patterns and model libraries
- Drives self-service analytics adoption reducing report backlog
- Mentors analysts and junior BI developers
- Bridges technical and business stakeholder communication
