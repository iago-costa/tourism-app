# Senior Data Architect — Skills

## Core Competencies

### Data Architecture
- Enterprise data architecture patterns (data mesh, data fabric, lambda, kappa)
- Data lakehouse architecture — medallion pattern, catalog, governance
- Multi-cloud and hybrid data architectures
- Real-time vs batch architecture trade-offs
- Federated data architectures and domain ownership

### Data Modeling
- Conceptual, logical, and physical data modeling
- Dimensional modeling (Kimball, Inmon)
- Data Vault 2.0 — hubs, links, satellites
- Graph data modeling (Neo4j, Neptune)
- Document and key-value data modeling

### Data Governance
- Data governance frameworks (DAMA-DMBOK)
- Data quality management — metrics, SLAs, remediation
- Master Data Management (MDM)
- Metadata management and data catalogs
- Data lineage and impact analysis

### Data Strategy
- Data maturity assessment and roadmapping
- Build vs buy evaluation for data tools
- Data team organization (centralized, embedded, data mesh)
- Cost optimization across data stack
- Vendor evaluation and technology selection

### Data Security & Compliance
- Data classification frameworks
- Encryption, masking, and tokenization strategies
- Privacy by design (GDPR, CCPA, LGPD, HIPAA)
- Access control policies (RBAC, ABAC)
- Audit logging and compliance reporting

### Technology Landscape
- Cloud data platforms — Snowflake, Databricks, BigQuery, Redshift
- Stream processing — Kafka, Flink, Spark Streaming
- Integration — Fivetran, Airbyte, dbt, Airflow
- Catalogs — DataHub, Atlan, Collibra, Alation
- Storage — Iceberg, Delta Lake, Parquet, S3/GCS

## Seniority Indicators
- Designs enterprise data architectures spanning 100+ data sources
- Creates and drives the organization's data strategy and roadmap
- Defines data governance frameworks adopted across all business units
- Evaluates and selects the data technology stack for the enterprise
- Mentors data engineering and analytics teams on architecture patterns
- Communicates data strategy to C-suite and non-technical stakeholders
