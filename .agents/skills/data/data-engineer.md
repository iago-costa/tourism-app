# Senior Data Engineer — Skills

## Core Competencies

### Data Pipeline Engineering
- Batch processing — Apache Spark, dbt, Airflow, Dagster
- Stream processing — Apache Kafka, Flink, Spark Streaming, Kinesis
- Orchestration — Airflow, Dagster, Prefect, Mage
- Data quality — Great Expectations, dbt tests, Soda, Monte Carlo
- CDC — Debezium, AWS DMS, Fivetran, Airbyte

### Data Warehousing
- Cloud warehouses — Snowflake, BigQuery, Redshift, Databricks Lakehouse
- Data modeling — star schema, snowflake schema, Data Vault 2.0, OBT
- Slowly changing dimensions (SCD Types 1-6)
- Partitioning, clustering, and materialization strategies
- Query optimization and cost management

### Data Lakes & Lakehouses
- Object storage — S3, GCS, Azure Blob, SeaweedFS
- Table formats — Apache Iceberg, Delta Lake, Apache Hudi
- Catalogs — AWS Glue, Hive Metastore, Unity Catalog
- File formats — Parquet, ORC, Avro, JSON
- Lakehouse architecture — medallion pattern (bronze/silver/gold)

### Infrastructure
- Kubernetes for data workloads (Spark on K8s, Airflow on K8s)
- Terraform for data infrastructure provisioning
- Container-based data pipelines
- Data infrastructure cost optimization
- Multi-cloud data architectures

### Data Governance
- Data catalogs (DataHub, Amundsen, Atlan, Collibra)
- Lineage tracking and impact analysis
- PII handling — masking, tokenization, encryption
- Access control and data classification
- Compliance (GDPR, CCPA, LGPD, HIPAA)

### Programming & Tools
- Python — pandas, PySpark, SQLAlchemy, data validation libraries
- SQL — advanced window functions, CTEs, recursive queries, query optimization
- Scala/Java — Spark development
- Git, CI/CD for data pipelines (dbt Cloud, GitHub Actions)

## Seniority Indicators
- Architects petabyte-scale data platforms serving hundreds of consumers
- Designs real-time and batch processing architectures
- Drives data quality and governance programs
- Reduces data pipeline costs by 50%+ through optimization
- Mentors data teams on engineering best practices
- Bridges gap between data engineering, analytics, and ML teams
