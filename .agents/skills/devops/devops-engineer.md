# Senior DevOps Engineer — Skills

## Core Competencies

### CI/CD & Automation
- Pipeline design — GitHub Actions, GitLab CI, Jenkins, CircleCI, Tekton
- Pipeline-as-code — reusable workflows, matrix builds, conditional stages
- Artifact management — Docker registries, Artifactory, Nexus
- Release strategies — blue-green, canary, rolling, feature flags
- Automated testing in pipelines — unit, integration, e2e, security scanning

### Containerization
- Docker — multi-stage builds, security hardening, image optimization
- Container registries — ECR, GCR, ACR, Harbor
- Docker Compose for local development environments
- Container security scanning (Trivy, Snyk, Anchore)

### Infrastructure as Code
- Terraform — modules, state management, workspaces, drift detection
- Ansible — playbooks, roles, inventories, vault
- Pulumi — TypeScript/Python/Go IaC
- CloudFormation / CDK for AWS-specific infrastructure

### Cloud Platforms
- AWS — EC2, ECS, EKS, Lambda, RDS, S3, CloudFront, Route53
- GCP — GKE, Cloud Run, Cloud Functions, BigQuery, Pub/Sub
- Azure — AKS, App Service, Functions, Cosmos DB
- Multi-cloud strategy and abstraction layers

### Orchestration
- Kubernetes — deployments, services, ingress, RBAC, network policies
- Helm — chart development, dependency management, hooks
- ArgoCD / Flux — GitOps workflows
- Service mesh — Istio, Linkerd

### Observability
- Logging — ELK Stack, Loki, CloudWatch Logs, Fluentd
- Metrics — Prometheus, Grafana, Datadog, CloudWatch Metrics
- Tracing — Jaeger, Zipkin, AWS X-Ray, OpenTelemetry
- Alerting — PagerDuty, OpsGenie, Alertmanager

## Seniority Indicators
- Designs end-to-end delivery pipelines reducing deployment time by 10×
- Implements infrastructure self-service reducing ops toil by 80%
- Leads cloud migration and modernization initiatives
- Drives DevOps culture adoption across engineering teams
- Designs disaster recovery and business continuity strategies
- Mentors engineers on automation and operational best practices
