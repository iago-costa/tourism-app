# Senior Infrastructure Architect — Skills

## Core Competencies

### Architecture Design
- Well-Architected Framework (AWS, GCP, Azure)
- Multi-region and multi-cloud architectures
- Hybrid cloud design — on-prem to cloud connectivity
- Infrastructure topology design — VPCs, subnets, peering, transit gateways
- Reference architecture creation and documentation

### Cloud Services
- **Compute**: EC2, GCE, Azure VMs, ECS, EKS, GKE, AKS, Lambda, Cloud Functions
- **Storage**: S3, GCS, Azure Blob, EFS, FSx
- **Databases**: RDS, Aurora, Cloud SQL, Cosmos DB, DynamoDB, Firestore
- **Networking**: VPC, Cloud VPN, Direct Connect, CloudFront, Cloud CDN
- **Security**: IAM, KMS, WAF, Shield, GuardDuty, Security Hub

### High Availability & DR
- Active-active and active-passive architectures
- RTO/RPO design and testing
- Automated failover and health checking
- Data replication strategies (sync, async, geo)
- Disaster recovery runbooks and rehearsals

### Security Architecture
- Zero-trust network architecture
- Identity and access management strategy
- Encryption at rest and in transit
- Network segmentation and micro-segmentation
- Compliance frameworks (SOC 2, ISO 27001, HIPAA, PCI DSS)

### Capacity Planning
- Infrastructure sizing and forecasting
- Performance modeling and benchmarking
- Cost-performance optimization
- Reserved instances and savings plans strategy
- Auto-scaling architecture and triggers

### Migration & Modernization
- Cloud migration strategies (6 Rs: Rehost, Replatform, Refactor, etc.)
- Application modernization roadmaps
- Database migration patterns (homogeneous, heterogeneous)
- Landing zone design and implementation
- Migration factory frameworks

## Seniority Indicators
- Designs infrastructure for 99.99%+ availability at enterprise scale
- Creates and maintains cloud architecture reference patterns
- Drives multi-million dollar cloud cost optimization initiatives
- Leads cloud migration programs spanning hundreds of applications
- Evaluates and selects cloud services and vendors for the organization
- Mentors teams on cloud architecture and operational best practices
