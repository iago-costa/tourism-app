# Senior Platform Engineer (DevOps) — Skills

## Core Competencies

### Cloud-Native Platforms
- Kubernetes — cluster design, multi-tenancy, federation, upgrades
- Service mesh — Istio, Linkerd, Consul, traffic management
- Serverless — Knative, AWS Lambda, Cloud Run, Azure Functions
- Container security — pod security standards, admission controllers, OPA

### Platform Automation
- Crossplane — infrastructure composition and claim-based provisioning
- Cluster API — Kubernetes cluster lifecycle management
- Operator Framework — custom controllers and CRDs
- GitOps — ArgoCD, Flux, pull-based deployment models

### Networking
- CNI plugins — Calico, Cilium, Flannel
- Ingress controllers — Nginx, Traefik, Istio Gateway
- DNS management — CoreDNS, ExternalDNS, Route53
- Network policies and micro-segmentation
- Load balancing — L4/L7, global load balancing

### Storage & State
- CSI drivers and storage classes
- Persistent volume management
- Database operators (CloudNativePG, Vitess, CockroachDB)
- Backup and disaster recovery (Velero)
- Stateful workload patterns in Kubernetes

### Cost Optimization
- FinOps practices — cost allocation, tagging, showback/chargeback
- Right-sizing and spot/preemptible instance strategies
- Resource quota management
- Cluster autoscaler tuning
- Cost monitoring dashboards (Kubecost, Infracost)

### Compliance & Governance
- Policy-as-code (OPA/Gatekeeper, Kyverno)
- CIS benchmarks for Kubernetes and cloud
- Supply chain security (Sigstore, cosign, SBOM)
- Audit logging and compliance reporting
- Multi-tenancy isolation strategies

## Seniority Indicators
- Architects and operates production Kubernetes platforms at scale
- Designs multi-cluster and multi-cloud platform strategies
- Reduces cloud spend by 30%+ through optimization programs
- Creates platform abstractions that accelerate developer velocity
- Drives platform security and compliance programs
- Mentors teams on cloud-native patterns and Kubernetes operations
