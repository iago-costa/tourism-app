# Senior Design System Engineer — Skills

## Core Competencies

### Design System Architecture
- Token-based design systems (color, typography, spacing, elevation)
- Component API design — props, variants, slots, composition
- Multi-brand/multi-theme architecture
- Semantic vs primitive token layers
- System versioning and release strategy

### Component Libraries
- React/Svelte/Vue component library development
- Storybook — stories, docs, addons, interaction testing
- Accessibility baked into components (ARIA, keyboard, focus)
- Compound component patterns for complex widgets
- Headless component architecture (Radix, React Aria)

### Design Tokens
- Token management (Figma Tokens, Style Dictionary, Tokens Studio)
- Token transformation pipelines (CSS, iOS, Android, JSON)
- Theming architecture — dark mode, high contrast, brand variants
- Token naming conventions and taxonomy
- Design-to-code token synchronization

### Documentation & Adoption
- Component documentation (usage, props, examples, do/don't)
- Contribution guidelines and governance
- Migration guides and codemods
- Adoption metrics and health dashboards
- Playground/sandbox environments

### Tooling & Infrastructure
- Monorepo management (Nx, Turborepo, Lerna)
- Package publishing (npm, Changeset, semantic-release)
- Visual regression testing (Chromatic, Percy, BackstopJS)
- Bundle size monitoring and tree-shaking optimization
- Automated accessibility auditing in CI

### Cross-Platform
- Web components for framework-agnostic delivery
- React Native component parity
- Token delivery to iOS (SwiftUI) and Android (Compose)
- Email template systems
- PDF/print design consistency

## Seniority Indicators
- Architects and leads the organization's design system
- Drives adoption across 10+ product teams
- Creates governance frameworks for contributions and reviews
- Measures design system ROI (dev velocity, consistency, accessibility)
- Collaborates with design leadership to evolve the visual language
- Mentors engineers and designers on system usage and contribution
