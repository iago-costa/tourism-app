# Senior Frontend Engineer — Skills

## Core Competencies

### Languages & Frameworks
- **Core**: TypeScript, JavaScript (ES2024+), HTML5, CSS3
- **Frameworks**: React, Next.js, Svelte/SvelteKit, Vue 3, Angular
- **State**: Redux Toolkit, Zustand, Jotai, TanStack Query, Pinia
- **Styling**: CSS Modules, Styled Components, Tailwind CSS, Vanilla Extract

### Architecture
- Component-driven development (Atomic Design, compound components)
- Micro-frontend architectures (Module Federation, Single SPA)
- Server-side rendering (SSR), static site generation (SSG), incremental static regeneration (ISR)
- Progressive Web Apps (PWA) — service workers, offline-first, push notifications
- Monorepo management (Nx, Turborepo, Pnpm workspaces)

### Performance
- Core Web Vitals optimization (LCP, FID, CLS, INP)
- Code splitting, tree shaking, lazy loading
- Image optimization (WebP, AVIF, responsive images)
- Bundle analysis and optimization (webpack, Vite, esbuild)
- Rendering strategies — client, server, streaming, partial hydration

### Testing
- Unit testing (Vitest, Jest, React Testing Library)
- E2E testing (Playwright, Cypress)
- Visual regression testing (Chromatic, Percy)
- Accessibility testing (axe-core, Lighthouse)
- Component testing (Storybook interaction tests)

### Tooling
- Build tools — Vite, webpack, esbuild, SWC, Turbopack
- Package management — pnpm, npm, Yarn Berry
- Linting & formatting — ESLint, Prettier, Biome
- API layer — REST, GraphQL (Apollo, urql), tRPC

### Accessibility & i18n
- WCAG 2.1 AA compliance
- ARIA patterns and semantic HTML
- Screen reader testing
- Internationalization (i18next, FormatJS)
- RTL layout support

## Seniority Indicators
- Architects frontend systems for large-scale applications
- Defines component libraries and design system foundations
- Optimizes Core Web Vitals across entire product lines
- Leads technical decisions on framework selection and migration
- Mentors frontend teams on best practices and code quality
- Drives frontend platform improvements (build, test, deploy)
