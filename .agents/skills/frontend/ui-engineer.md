# Senior UI Engineer — Skills

## Core Competencies

### Visual Implementation
- Pixel-perfect implementation from design specifications (Figma, Sketch)
- CSS mastery — Grid, Flexbox, custom properties, container queries, view transitions
- Animation — CSS transitions, Web Animations API, Framer Motion, GSAP, Lottie
- Responsive design — mobile-first, fluid typography, adaptive layouts
- Dark mode and theming systems

### Component Engineering
- Headless component patterns (Radix UI, Headless UI, React Aria)
- Compound component patterns for complex UIs
- Controlled vs uncontrolled component design
- Render prop and slot patterns
- Form libraries (React Hook Form, Formik, Zod validation)

### Interaction Design
- Drag-and-drop (dnd-kit, react-beautiful-dnd)
- Virtualization for large lists (TanStack Virtual, react-window)
- Gesture handling and touch events
- Keyboard navigation patterns
- Focus management and trap patterns

### Design-to-Code
- Figma plugin development and design token extraction
- Design token management (Style Dictionary, Tokens Studio)
- Handoff workflows — inspecting, measuring, annotating
- Pixel-perfect implementation verification tools
- Prototype-to-production translation

### Cross-Browser Compatibility
- Browser testing (BrowserStack, Sauce Labs)
- Progressive enhancement strategies
- Polyfill management and feature detection
- CSS vendor prefix strategies (PostCSS, Autoprefixer)
- Print stylesheet design

### Motion & Micro-Interactions
- Page transitions and route animations
- Loading state animations (skeleton screens, shimmer)
- Feedback animations (success, error, progress)
- Scroll-linked animations (Intersection Observer, ScrollTimeline)
- Performance-optimized animations (transform, opacity, will-change)

## Seniority Indicators
- Creates UI component libraries used across multiple products
- Defines animation and interaction standards for the organization
- Bridges the gap between design and engineering teams
- Optimizes rendering performance for complex interactive UIs
- Mentors engineers on CSS architecture and component patterns
- Drives accessibility excellence across all UI components
