# Senior Web Performance Engineer — Skills

## Core Competencies

### Core Web Vitals
- LCP (Largest Contentful Paint) — resource prioritization, preloading, server timing
- INP (Interaction to Next Paint) — main thread optimization, task scheduling
- CLS (Cumulative Layout Shift) — layout stability, font loading, image sizing
- FCP (First Contentful Paint) — critical rendering path optimization
- TTFB (Time to First Byte) — server response optimization, CDN tuning

### Bundle Optimization
- Code splitting strategies (route-based, component-based, dynamic imports)
- Tree shaking and dead code elimination
- Bundle analysis (webpack-bundle-analyzer, source-map-explorer)
- Module resolution and dependency optimization
- Compression (Brotli, gzip) and minification

### Rendering Performance
- Virtual DOM reconciliation optimization
- Rendering strategies — SSR, SSG, ISR, streaming SSR, partial hydration
- React Server Components and selective hydration
- Web Workers for off-main-thread computation
- requestAnimationFrame and requestIdleCallback optimization

### Network Optimization
- Resource hints (preload, prefetch, preconnect, dns-prefetch)
- HTTP/2 and HTTP/3 optimization
- CDN configuration and edge computing
- Service workers for caching and offline support
- Image optimization (WebP, AVIF, responsive images, lazy loading)

### Measurement & Monitoring
- Real User Monitoring (RUM) — web-vitals library, SpeedCurve, Calibre
- Synthetic monitoring — Lighthouse CI, WebPageTest, PageSpeed Insights
- Performance budgets and CI enforcement
- Custom performance marks and measures
- A/B testing performance impact analysis

### Font & Media Optimization
- Font loading strategies (font-display, variable fonts, subsetting)
- Image format selection and art direction
- Video optimization and lazy loading
- SVG optimization and animation
- Icon delivery strategies (sprite, inline, font, component)

## Seniority Indicators
- Achieves 90+ Lighthouse performance scores across product lines
- Defines performance budgets and enforces them in CI/CD pipelines
- Reduces bundle sizes by 50%+ through systematic optimization
- Creates performance monitoring dashboards and alerting
- Drives performance culture across engineering teams
- Mentors developers on performance-first development patterns
