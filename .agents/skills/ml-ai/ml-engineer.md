# Senior ML Engineer — Skills

## Core Competencies

### ML Fundamentals
- Supervised learning — classification, regression, ensemble methods
- Unsupervised learning — clustering, dimensionality reduction, anomaly detection
- Deep learning — CNNs, RNNs, Transformers, attention mechanisms
- NLP — text classification, NER, sentiment analysis, embeddings
- Computer Vision — object detection, segmentation, image classification
- Recommendation systems — collaborative filtering, content-based, hybrid

### ML Engineering
- Feature engineering — feature stores (Feast, Tecton), feature pipelines
- Model training — distributed training, hyperparameter tuning, AutoML
- Model serving — TensorFlow Serving, Triton, TorchServe, BentoML
- Model monitoring — drift detection, performance degradation, retraining triggers
- Experiment tracking — MLflow, Weights & Biases, Neptune

### Frameworks & Tools
- PyTorch, TensorFlow, JAX, scikit-learn, XGBoost, LightGBM
- Hugging Face Transformers, Sentence Transformers
- Pandas, NumPy, Polars — data manipulation
- ONNX — model interoperability
- GPU computing — CUDA, cuDNN, mixed precision training

### Data Engineering for ML
- Data versioning — DVC, LakeFS
- Data labeling — Label Studio, Scale AI, Snorkel
- Data validation — Great Expectations, TensorFlow Data Validation
- Feature stores — offline and online serving
- ETL pipelines optimized for ML workloads

### Infrastructure
- GPU clusters — NVIDIA, cloud GPU instances
- Kubernetes for ML — Kubeflow, Ray, Seldon Core
- Cloud ML services — SageMaker, Vertex AI, Azure ML
- Model registries — MLflow, Seldon, Vertex AI Registry
- Cost optimization — spot instances, model optimization (quantization, pruning)

### Responsible AI
- Fairness and bias detection
- Model interpretability — SHAP, LIME, attention visualization
- Privacy-preserving ML — differential privacy, federated learning
- AI ethics and governance frameworks
- Regulatory compliance (EU AI Act, industry-specific regulation)

## Seniority Indicators
- Architects end-to-end ML systems from data to production serving
- Reduces model training costs by 50%+ through infrastructure optimization
- Defines ML engineering standards and best practices
- Mentors ML teams on engineering rigor and production readiness
- Bridges the gap between research and production ML
- Drives responsible AI initiatives across the organization
