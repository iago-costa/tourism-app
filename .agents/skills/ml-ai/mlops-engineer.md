# Senior MLOps Engineer — Skills

## Core Competencies

### ML Pipeline Orchestration
- Kubeflow Pipelines, Vertex AI Pipelines, SageMaker Pipelines
- Airflow/Dagster for ML workflows
- Feature pipeline automation
- Training pipeline optimization (caching, parallelism)
- Pipeline versioning and reproducibility

### Model Lifecycle Management
- Model registries — MLflow, Vertex AI, SageMaker Model Registry
- Model versioning, staging, and promotion workflows
- A/B testing and shadow deployment for models
- Model rollback and canary deployment strategies
- Automated retraining triggers and schedules

### Serving Infrastructure
- Model serving — TensorFlow Serving, Triton, Seldon Core, BentoML
- Real-time vs batch inference architectures
- GPU scheduling and multi-model serving
- Autoscaling for inference workloads
- Edge deployment — TensorFlow Lite, ONNX Runtime, Core ML

### Monitoring & Observability
- Data drift detection — Evidently AI, WhyLabs, NannyML
- Model performance monitoring (accuracy, latency, throughput)
- Feature drift and skew detection
- Alerting on model degradation
- A/B test result analysis and significance testing

### Infrastructure
- Kubernetes for ML workloads (Kubeflow, Ray on K8s)
- GPU cloud instances — spot/preemptible strategies
- Cloud ML platforms — SageMaker, Vertex AI, Azure ML
- Storage optimization for ML artifacts (models, datasets)
- Infrastructure as code for ML environments

### Data Management
- Feature stores — Feast, Tecton, Hopsworks
- Data versioning — DVC, LakeFS
- Dataset management and lineage
- Data quality monitoring for ML
- Privacy-compliant data pipelines

## Seniority Indicators
- Architects the organization's ML platform and infrastructure
- Reduces model deployment time from weeks to hours
- Defines MLOps maturity model and drives adoption
- Creates reusable ML pipeline templates and components
- Bridges ML research and production engineering teams
- Optimizes ML infrastructure costs by 40%+
