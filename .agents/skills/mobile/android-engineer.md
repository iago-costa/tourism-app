# Senior Android Engineer — Skills

## Core Competencies

### Kotlin & Java
- Kotlin — coroutines, flows, sealed classes, extension functions, multiplatform
- Jetpack Compose — declarative UI, state management, animations, navigation
- Android Views — ConstraintLayout, RecyclerView, custom views (legacy)
- Kotlin Coroutines & Flow — structured concurrency, StateFlow, SharedFlow

### Architecture & Patterns
- MVVM with Android Architecture Components
- MVI (Model-View-Intent) pattern
- Clean Architecture with use cases and repositories

- Room — database, migrations, relations, Flow integration
- WorkManager — background processing, constraints, chaining
- Navigation Component — type-safe navigation, deep links
- DataStore — preferences and Proto DataStore

### Networking & Data

- Ktor Client — multiplatform networking
- GraphQL (Apollo Kotlin)
- Protocol Buffers and gRPC
- Firebase — Auth, Firestore, Cloud Messaging, Crashlytics

### Testing & Quality
- JUnit 5, MockK, Turbine — unit testing
- Espresso, Compose Testing — UI testing
- Robolectric — fast unit tests with Android framework
- Screenshot testing (Paparazzi, Shot)
- CI/CD (GitHub Actions, Bitrise, Fastlane)

### Distribution & Performance
- Google Play Console — releases, A/B testing, staged rollouts
- App Bundle and dynamic feature modules
- ProGuard/R8 — code shrinking, obfuscation, optimization
- Baseline Profiles and Macrobenchmark
- Memory leak detection (LeakCanary), ANR prevention
