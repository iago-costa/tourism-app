# Senior Flutter Engineer — Skills

## Core Competencies

### Dart & Flutter Core
- Dart 3+ — records, patterns, sealed classes, extension types
- Flutter 3+ — Material 3, adaptive layouts, platform channels
- Widget architecture — composition, keys, lifecycle, BuildContext
- State management — Riverpod, BLoC, Provider, GetX

### Multi-Platform
