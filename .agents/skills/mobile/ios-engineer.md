# Senior iOS Engineer — Skills

## Core Competencies

### Swift & Objective-C
- Swift 5.9+ — concurrency (async/await, actors, structured concurrency), macros, result builders
- SwiftUI — declarative UI, state management, animations, navigation
- UIKit — Auto Layout, collection views, custom transitions
- Combine — reactive programming, publishers, operators
- Objective-C interop and legacy codebase modernization

### Architecture & Patterns
- MVVM, MVC, VIPER, TCA (The Composable Architecture)
- Dependency injection (Swinject, Factory, manual)
- Coordinator pattern for navigation
- Clean Architecture and modular design
- Protocol-oriented programming

### Apple Frameworks
- Core Data, SwiftData — persistence, migration, CloudKit sync
- Core Location, MapKit — location services, geofencing
- AVFoundation — audio/video capture and processing
- Core ML, Vision — on-device machine learning
- WidgetKit, App Intents, Live Activities

### Networking & Data
- URLSession, Alamofire — networking, caching, certificate pinning
- REST, GraphQL (Apollo iOS), WebSocket
- Codable — JSON encoding/decoding, custom coding keys
- Keychain — secure storage, biometric authentication
- Firebase — Auth, Firestore, Analytics, Crashlytics

### Testing & Quality
- XCTest — unit, integration, UI testing
- XCUITest — UI automation and accessibility testing
- Snapshot testing (Swift Snapshot Testing)
- Performance testing and profiling (Instruments)
- Continuous integration (Xcode Cloud, Fastlane, GitHub Actions)

### App Store & Distribution
- App Store Connect — metadata, screenshots, TestFlight
- Code signing, provisioning profiles, entitlements
- In-app purchases and subscriptions (StoreKit 2)
- App size optimization and binary analysis
- Privacy manifests and App Tracking Transparency

## Seniority Indicators
- Architects modular iOS applications with clear separation of concerns
- Leads SwiftUI migration from UIKit-based codebases
- Defines iOS development standards and code review guidelines
- Optimizes app performance using Instruments profiling
- Mentors iOS team on Swift best practices and Apple ecosystem
- Drives adoption of new Apple frameworks and platform capabilities
