# Senior React Native Engineer — Skills

## Core Competencies

### React Native Core
- React Native 0.73+ — New Architecture (Fabric, TurboModules, JSI)
- Expo — managed and bare workflows, EAS Build, EAS Update
- Metro bundler configuration and optimization
- Hermes engine — performance optimization, debugging
- TypeScript — strict typing for React Native

### Architecture & State
- State management — Zustand, Redux Toolkit, Jotai, MobX
- Navigation — React Navigation 6+, deep linking, authentication flows
- Data fetching — TanStack Query, SWR, offline-first with WatermelonDB
- Module architecture — feature-based, barrel exports, monorepo (Nx)
- Error boundaries and crash recovery

### Native Integration
- Native Modules — Turbo Native Modules, JSI bridge
- Platform-specific code — Platform.select, .ios/.android files
- Native view integration — Fabric components
- Bluetooth, NFC, biometrics, camera, push notifications
- React Native for macOS, Windows, tvOS

### Performance
- FlatList and FlashList optimization for large lists
- Animation — Reanimated 3, gesture handling (RNGH)
- Memory management and JS thread optimization
- Bundle optimization and code splitting
- Profiling with Flipper, React DevTools, Hermes Profiler

### Testing & CI/CD
- Jest — unit testing, mocking native modules
- Detox — E2E testing on simulators/devices
- React Native Testing Library
- EAS Build and EAS Submit for CI/CD
- Fastlane integration for native build pipelines

### Native Ecosystem
- CocoaPods and Swift/Objective-C bridging (iOS)
- Gradle and Kotlin/Java bridging (Android)
- App Store and Google Play submission
- OTA updates (EAS Update, CodePush)
- Crashlytics, Analytics, and performance monitoring

## Seniority Indicators
- Architects large-scale React Native apps with native module integration
- Leads migration to New Architecture (Fabric, TurboModules)
- Optimizes app performance to match native app quality
- Defines cross-platform code sharing strategies
- Mentors mobile team on React Native best practices
- Drives decision-making on native vs cross-platform scope
