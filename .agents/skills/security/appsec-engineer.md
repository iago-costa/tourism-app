# Senior AppSec Engineer — Skills

## Core Competencies

### Security Testing
- SAST — CodeQL, Semgrep, SonarQube, Checkmarx
- DAST — OWASP ZAP, Burp Suite Pro, Nuclei
- IAST — Contrast Security, Hdiv
- SCA — Snyk, Dependabot, Socket.dev, Trivy
- Manual code review for security vulnerabilities

### Vulnerability Management
- Vulnerability triage and risk scoring (CVSS, EPSS)
- Remediation guidance and developer coaching
- False positive management and tuning
- Vulnerability tracking and SLA enforcement
- Bug bounty program management

### Threat Modeling
- STRIDE, PASTA, Attack Trees methodologies
- Data flow diagram analysis
- Threat library maintenance
- Architecture security reviews
- Risk assessment and prioritization

### Secure Development
- Secure coding standards per language
- Security design patterns (input validation, output encoding, parameterized queries)
- Cryptography — hashing, encryption, key management, digital signatures
- Session management and anti-CSRF tokens
- Content Security Policy, CORS, security headers

### API Security
- OWASP API Security Top 10
- API authentication and authorization testing
- API fuzzing and schema validation
- GraphQL security (introspection, batching, depth limiting)
- Rate limiting and abuse prevention

### Security Automation
- CI/CD security integration (pre-commit hooks, pipeline gates)
- Custom security rules and policies (Semgrep, CodeQL)
- Automated vulnerability remediation workflows
- Security dashboards and metrics reporting
- ChatOps for security notifications

## Seniority Indicators
- Owns the application security program for the organization
- Designs and implements the Secure SDLC framework
- Creates custom security rules and tooling reducing vulnerabilities by 70%+
- Runs security champions program across development teams
- Leads threat modeling workshops for critical systems
- Presents security findings and recommends investments to leadership
