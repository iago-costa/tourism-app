# Senior Cloud Security Architect — Skills

## Core Competencies

### Cloud Security Architecture
- Multi-cloud security strategy (AWS, GCP, Azure)
- Zero-trust architecture design and implementation
- Cloud-native security controls and guardrails
- Landing zone security design
- Security reference architectures per cloud provider

### Identity & Access Management
- IAM strategy — least privilege, just-in-time access
- Cross-cloud identity federation
- Service account and workload identity management
- PAM — Privileged Access Management
- SSO and MFA architecture

### Data Protection
- Encryption at rest — KMS, HSM, customer-managed keys
- Encryption in transit — TLS, mTLS, certificate management
- Data classification and handling policies
- DLP — Data Loss Prevention strategies
- Tokenization and anonymization

### Network Security
- Virtual network architecture — VPCs, subnets, security groups
- Zero-trust networking — BeyondCorp, ZTNA
- WAF and DDoS protection (CloudFlare, AWS Shield, Cloud Armor)
- Private connectivity — VPN, Direct Connect, Private Link
- Service mesh security — Istio authorization, mTLS

### Cloud Security Posture Management
- CSPM tools — Prisma Cloud, Wiz, Orca, Prowler
- CIS benchmarks for cloud platforms
- Infrastructure-as-code security scanning (Checkov, tfsec, KICS)
- Container security — image scanning, runtime protection, admission control
- Supply chain security — SBOM, Sigstore, cosign

### Compliance & Governance
- Compliance automation — policy-as-code, compliance-as-code
- Regulatory frameworks — SOC 2, ISO 27001, PCI DSS, HIPAA, FedRAMP
- Cloud audit logging and forensics
- Governance frameworks for multi-cloud environments
- Risk management and third-party assessment

## Seniority Indicators
- Designs cloud security architecture for enterprise multi-cloud environments
- Creates security reference architectures adopted across the organization
- Leads compliance certification programs (SOC 2, ISO 27001)
- Evaluates and selects cloud security tooling for the enterprise
- Drives zero-trust adoption and network transformation
- Communicates cloud security strategy to C-suite and board
