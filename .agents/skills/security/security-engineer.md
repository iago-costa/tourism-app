# Senior Security Engineer — Skills

## Core Competencies

### Application Security
- Secure coding practices across multiple languages
- OWASP Top 10 identification and remediation
- Static analysis (SAST) — Semgrep, SonarQube, CodeQL
- Dynamic analysis (DAST) — OWASP ZAP, Burp Suite
- Dependency scanning (SCA) — Snyk, Dependabot, Trivy

### Infrastructure Security
- Cloud security — AWS Security Hub, GCP Security Command Center, Azure Sentinel
- Container security — image scanning, runtime protection, pod security
- Network security — firewalls, IDS/IPS, VPN, micro-segmentation
- Infrastructure hardening — CIS benchmarks, OS hardening, patch management
- Secrets management — HashiCorp Vault, AWS Secrets Manager, sealed secrets

### Identity & Access
- Authentication — OAuth 2.0, OIDC, SAML, WebAuthn/FIDO2, MFA
- Authorization — RBAC, ABAC, policy engines (OPA, Cedar)
- Identity providers — Okta, Auth0, Keycloak, Azure AD
- Service-to-service auth — mTLS, SPIFFE/SPIRE
- API security — API keys, JWT validation, rate limiting

### Security Operations
- SIEM — Splunk, Elastic SIEM, Azure Sentinel, Datadog Security
- Incident response — playbooks, forensics, containment, recovery
- Vulnerability management — scanning, prioritization, remediation tracking
- Threat intelligence — IoC feeds, threat hunting, MITRE ATT&CK
- Security monitoring and alerting

### Compliance & Governance
- Compliance frameworks — SOC 2, ISO 27001, PCI DSS, HIPAA, GDPR
- Risk assessment and management
- Security policies and standards documentation
- Audit preparation and evidence collection
- Third-party vendor security assessments

### DevSecOps
- Security in CI/CD — SAST, DAST, SCA, container scanning in pipelines
- Security-as-code — policy-as-code, compliance-as-code
- Shift-left security practices
- Security champions program
- Developer security training and awareness

## Seniority Indicators
- Designs organization-wide security architecture and strategy
- Leads incident response and coordinates cross-team mitigation
- Builds security tooling and automation reducing manual review by 80%
- Drives DevSecOps culture adoption across engineering
- Mentors engineers on secure development practices
- Communicates security risks and investments to leadership
